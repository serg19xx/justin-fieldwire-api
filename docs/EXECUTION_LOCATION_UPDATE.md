# Обновление типа поля execution_location

## Изменения

### Тип поля изменен с `SET('server','auto')` на `VARCHAR(20)`

**Причина:** Для двух значений (`server`, `auto`) плюс `NULL` тип `VARCHAR(20)` более простой и эффективный.

### Обновленные файлы:

1. **`scripts/add-execution-location-field.sql`**
   ```sql
   ALTER TABLE fw_event_rules 
   ADD COLUMN execution_location VARCHAR(20) DEFAULT NULL;
   ```

2. **`src/Controllers/EventRulesController.php`**
   - Добавлена валидация длины (максимум 20 символов)
   - Сохранена валидация допустимых значений (`server`, `auto`)

3. **`docs/EXECUTION_LOCATION.md`**
   - Обновлено описание типа поля
   - Добавлена информация о валидации длины
   - Обновлены примеры SQL миграции

### Валидация:

- **Допустимые значения:** `server`, `auto`
- **Максимальная длина:** 20 символов
- **По умолчанию:** `NULL`
- **Обязательность:** необязательное поле

### Преимущества VARCHAR(20):

1. **Простота** - нет необходимости в сложном типе SET
2. **Гибкость** - можно легко добавить новые значения в будущем
3. **Производительность** - VARCHAR эффективнее для небольших строк
4. **Совместимость** - работает со всеми версиями MySQL

### Примеры использования:

```json
{
  "execution_location": "server"  // Выполнение на сервере
}

{
  "execution_location": "auto"    // Выполнение в системе автоматизации
}

{
  "execution_location": null     // Выполнение везде (по умолчанию)
}
```

## Заключение

Изменение типа поля с `SET` на `VARCHAR(20)` упрощает структуру базы данных и делает систему более гибкой для будущих расширений.
