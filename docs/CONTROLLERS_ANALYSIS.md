## 🎯 **Приоритеты интеграции**

### **Высокий приоритет (критически важные операции):**
1. **TaskController** - все CRUD операции
2. **ProjectController** - все CRUD операции
3. **AuthController** - login, register, logout
4. **TwoFactorController** - enable/disable 2FA
5. **ProfileController** - updateProfile, uploadAvatar

### **Средний приоритет (важные бизнес-операции):**
6. **ProjectTeamController** - управление командой
7. **WorkerController** - приглашения и статусы
8. **PatientController** - управление пациентами
9. **PhysicianController** - управление врачами

### **Низкий приоритет (справочные данные):**
10. **MedicalClinicController** - управление клиниками
11. **PharmacyController** - управление аптеками
12. **PharmacistController** - управление фармацевтами
13. **DriverController** - управление водителями

## 📊 **Типы событий для каждого контроллера**

### **TaskController:**
- `TASK_CREATED` - создание задачи
- `TASK_UPDATED` - обновление задачи
- `TASK_DELETED` - удаление задачи
- `TASK_STATUS_CHANGED` - изменение статуса
- `TASK_ASSIGNEES_CHANGED` - изменение исполнителей
- `TASK_SCHEDULE_CHANGED` - изменение расписания

### **ProjectController:**
- `PROJECT_CREATED` - создание проекта
- `PROJECT_UPDATED` - обновление проекта
- `PROJECT_DELETED` - удаление проекта
- `PROJECT_STATUS_CHANGED` - изменение статуса
- `PROJECT_MANAGER_CHANGED` - изменение менеджера

### **ProfileController:**
- `PROFILE_UPDATED` - обновление профиля
- `AVATAR_UPLOADED` - загрузка аватара
- `PROFILE_STATUS_CHANGED` - изменение статуса пользователя

### **AuthController:**
- `USER_LOGIN` - вход в систему
- `USER_LOGOUT` - выход из системы
- `USER_REGISTERED` - регистрация пользователя

### **TwoFactorController:**
- `2FA_ENABLED` - включение 2FA
- `2FA_DISABLED` - отключение 2FA

## ⚠️ **Важные замечания**

1. **Не логировать GET операции** - только изменения данных
2. **Логировать критические операции** - аутентификация, 2FA, удаления
3. **Условное логирование** - только значительные изменения
4. **Безопасность** - не логировать пароли и чувствительные данные
5. **Производительность** - не замедлять основные операции
